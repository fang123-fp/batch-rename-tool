# 批量文件重命名台

这是一个纯前端工具。

- 只在本机使用时：直接双击 `index.html` 或用浏览器打开即可，PDF 也会先尝试直接解析
- 如果你的浏览器对 `file://` 下的 PDF 或 OCR 有限制：启动局域网服务器后再使用

## 功能
- 一次选择多个文件
- 上传后按列表展示所有已选文件
- 自定义字段，例如 `姓名`、`编号`
- 自动从文件内容中读取字段值
- 用模板控制文件名，例如 `{姓名}-{编号}`、`{姓名}@{编号}`
- 自动读取失败时可在文件列表里手动补值
- 自动保留原始后缀
- 自动处理重名结果
- 导出重命名后的 ZIP

## 使用步骤
1. 上传文件
说明：选择或拖入多个文件，文件会立刻以列表形式显示，工具会自动读取文件内容
2. 配置字段
说明：填写你要提取的字段名，例如 `姓名`、`编号`
3. 设置命名模板并下载
说明：输入模板，例如 `{姓名}-{编号}`，必要时手动修正未匹配字段，然后点击 `重新命名并下载 ZIP`

## 局域网访问

如果直接打开时遇到浏览器限制，改用下面的局域网方式最稳。

### Windows
1. 双击 `start_lan_server.bat`
2. 保持弹出的窗口不要关闭
3. 在同一局域网的其他电脑里打开窗口里显示的地址，例如 `http://192.168.x.x:8123`

### macOS
1. 双击 `start_lan_server.command`
2. 保持终端窗口不要关闭
3. 在同一局域网的其他电脑里打开 `http://这台电脑的IP:8123`

### 通用 Node.js 方式
如果电脑安装了 Node.js，也可以运行：

```bash
node server.js
```

启动后会显示可访问地址。

## 模板规则
- 使用 `{字段名}` 表示占位符
- 例如：`{姓名}-{编号}`
- 例如：`{姓名}@{编号}`

## 内容读取规则
- 当前优先支持：`txt`、`csv`、`tsv`、`json`、`md`、`html`、`xml`、`pdf`、`docx`
- 字段内容建议写成：
  - `姓名: 张三`
  - `编号：001`
- 也支持：
  - `姓名 张三 编号 001`
  - `姓名` 换行后下一行是 `张三`
- 如果某个文件类型暂不支持自动读取，页面会明确提示，你可以手动补字段值后继续下载

## 说明
- 这个工具不会直接修改你电脑上的原始文件
- 它会把重命名后的文件导出为一个 ZIP 下载包
- ZIP 里会附带一个 `rename-manifest.json` 作为重命名清单
- 首次开启局域网服务时，系统防火墙可能会弹出提示，需要允许局域网访问
