# 2026-06-11 识别收口与性能闭环

## Goal

- 用用户当前真实样本建立可重复回归闭环
- 修复当前仍然识别错误的 PDF 样本，优先保证字段准确率
- 在不牺牲准确率的前提下，继续缩短批量识别总耗时
- 形成“总控 -> 开发 -> 测试 -> 打回”的可执行工作流

## Success Criteria

- `/Users/fangpei/Desktop/导出内容资料` 中当前 11 份 PDF 都能完成识别
- 对于已知可从文件名或人工校验确认的字段，结果必须与期望一致
- 证书类样本至少稳定覆盖：
  - `证书编号`
  - `客户名称`
  - `地址`
  - `仪器名称`
  - `管理编号`
  - `校准日期`
- 建立脚本化批量回归，能一次性输出：
  - 每份文件字段结果
  - 失败字段
  - 总耗时
  - 单文件耗时
- 修复完成后重新回归，不能只凭单文件或手工点击宣称完成

## Non-Goals

- 本轮不引入云 OCR 或第三方在线识别服务
- 本轮不重做整套 UI
- 本轮不把“目录模式”作为主开发目标
