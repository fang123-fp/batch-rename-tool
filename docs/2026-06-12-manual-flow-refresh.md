# 2026-06-12 手动触发命名流程改版

## Goal
- 把主流程改成：上传文件 -> 配置字段 -> 设置命名模板 -> 点击“批量替换名称”后再开始读取文字
- 从结果列表区移除“从内容重新读取”入口，避免与主 CTA 重复
- 以更简洁、干净的单页工作台样式重做界面

## Scope
- 调整首页结构、按钮位置、状态文案和表格展示
- 保留现有 OCR / PDF / ZIP 导出能力
- 保留手动修正字段值能力

## Interaction spec

### Primary flow
1. 用户上传一份或多份文件
2. 用户配置字段
3. 用户设置命名模板
4. 用户点击模板区内“批量替换名称”
5. 系统开始读取文字、回填字段、生成预览名称
6. 用户确认无误后下载 ZIP

### Behavior changes
- 上传文件后不再自动开始识别
- 字段新增、删除、重命名后不再自动重新读取
- 结果表格新增“预览名称”列
- 下载 ZIP 前，如果文件或字段刚改过但还没重新执行，会阻止导出并提示先运行“批量替换名称”

## UI notes
- 顶部采用简洁编辑台风格，突出 `Product Design` 调性
- 用 1-2-3-4 编号强化顺序感
- 模板区承担唯一主 CTA
- 结果区仅保留手动修正、导出诊断和下载动作

## Acceptance
- 上传文件后列表只显示排队状态，不会自动开始识别
- 页面中不再出现“从内容重新读取”按钮
- 点击“批量替换名称”后才会启动内容读取
- 结果表格能显示字段值和预览名称
- 界面在桌面和移动端都能正常排版
